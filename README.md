## Overview

This repository is a topic-organized collection of Jupyter notebooks for learning NumPy, the foundational Python library for numerical computing. It starts with array creation and core operations, then progresses toward more advanced NumPy concepts.

The material is intended for learners who know basic Python and want to work more effectively with numerical data used in analytics, scientific computing, and machine learning.

## Learning roadmap

### 01 · NumPy Fundamentals

The fundamentals section introduces core array concepts and common operations:

- Creating NumPy arrays
- Array attributes
- Changing data types
- Array operations
- Array functions
- Indexing and slicing
- Iterating over arrays
- NumPy arrays compared with Python lists
- Mathematical functions
- Handling missing values
- Plotting graphs

### 02 · Advanced NumPy

The advanced section contains a notebook on NumPy functions. Further topics can be added as the learning material grows.

## Getting started

### Prerequisites

- Python 3.9 or later
- JupyterLab or Jupyter Notebook

### Install dependencies

From a terminal, install NumPy and JupyterLab:

```bash
python -m pip install numpy jupyterlab
```

On Windows, if `python` is not recognized, use:

```powershell
py -m pip install numpy jupyterlab
```

### Run the notebooks

Clone or download this repository, open a terminal in its root folder, and start JupyterLab:

```bash
jupyter lab
```

Open a notebook from `01_Numpy_Fundamentals` or `02_Advance_Numpy` in the Jupyter interface and run its cells from top to bottom.

## Recommended learning sequence

1. Work through the fundamentals notebooks in numerical order.
2. Run each cell and inspect the resulting arrays and output.
3. Modify input values and compare the results.
4. Continue to the advanced section once the fundamentals are comfortable.
